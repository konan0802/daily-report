# Daily Report
日々の学びと経験を記録するリポジトリ

## 目的
- 一度聞いたことを忘れないようにする
- 一度体験したことを形式知化する
- 知識を検索可能な形で蓄積する

---

## 使い方
### 📋 今日のタスク
**朝一番に記入** - 今日やる予定のことをチェックボックスで記入

- 前日の「明日やること」を転記
- 定例会議やミーティング
- 取り組む予定の開発タスク
- 調べたいこと、聞きたいこと

チェックボックス `- [ ]` を使うことで、完了時に `- [x]` に変更できる

### 📝 出来事・メモ（時系列）
**メインセクション** - 仕事中に起きたことをその都度追記

書く内容の例：
- 会議での決定事項や聞いた話
- 実行したコマンドやトラブルシューティング
- 質問した内容と回答
- レビューでのフィードバック
- ドキュメントを読んで理解したこと

**書き方のコツ**：
- 後回しにせず、その都度メモする（5秒でOK）
- 完璧な文章でなくてOK、箇条書きやメモ書きで素早く記録
- コードやコマンドはコピペして、後で再現できるようにしておく
- 重要度に関わらず、気になったことは何でも書く

### ✅ 今日やったこと
終業時に時系列セクションを見返してサマリーを記入

### 💭 気づき・学び
特に重要な学びや気づきをピックアップ

### ❓ 疑問点・明日やること
解決していない疑問点や、明日やるべきことをメモ

### 🏷️ タグ
後で検索しやすいようタグを付与（技術名、プロジェクト名など）

## 将来の構想
### 🎤 音声入力による自動メモ記録

仕事中に常に横の画面でこのリポジトリを開いておき、思いついたことを口頭で話すだけでメモを追記できる仕組みを構築したい。

#### 具体的な使用シーン
**会議中・作業中の即時メモ**
```
[音声入力] 「えーと、田中さんとのミーティングで、認証フローの実装を来週までに終わらせることになった。
あと、エラーハンドリングのところで指摘があって、リトライ処理を追加する必要があるって話だった。」

↓ AIが自動整形

[出力結果]
#### 14:30 田中さんとのミーティング
- 認証フローの実装期限：来週まで
- エラーハンドリングにリトライ処理を追加する必要あり
```

**トラブルシューティングの記録**
```
[音声入力] 「ビルドエラーが出てて、どうやらNode.jsのバージョンが古いみたい。
nvm use 20 で切り替えたら直った。これpackage.jsonに書いといた方がいいな。」

↓ AIが自動整形

[出力結果]
#### 16:15 ビルドエラー対応
- **問題**: Node.jsバージョン起因のビルドエラー
- **解決**: `nvm use 20` でバージョン切り替え
- **TODO**: package.jsonにNode.jsバージョン要件を記載
```

#### 実現アプローチ
1. **音声認識層**
   - [Wispr Flow](https://wisprflow.ai/) のような高精度音声認識ツールを活用
   - ショートカットキーで音声入力のON/OFF切り替え
   - バックグラウンドで常時待機

2. **AI整形層**
   - LLM APIを使って音声テキストを構造化
   - 日報フォーマットに合わせて自動分類（出来事・メモ、気づき、疑問など）
   - 時刻の自動付与、箇条書き化、コマンドのコードブロック化

3. **自動追記層**
   - Gitリポジトリの本日日付ファイルに自動追記
   - マージコンフリクトを避けるため、ファイルの末尾に追記
   - 定期的なコミット＆プッシュ（オプション）

#### 開発ステップ
- [ ] Phase 1: Wispr Flow等の音声入力ツールの評価・選定
- [ ] Phase 2: 音声テキストをLLMで整形するスクリプト作成
- [ ] Phase 3: 日報ファイルへの自動追記機能の実装
- [ ] Phase 4: ショートカットキーでの起動・停止機能
- [ ] Phase 5: 実運用テスト＆改善

#### 期待される効果
- タイピングの中断なしで、作業の流れを止めずにメモ可能
- 会議中でも画面共有しながら口頭でメモを残せる
- 「後でまとめよう」による記憶の欠落を防止
- 日報作成の心理的ハードルが大幅に下がる
