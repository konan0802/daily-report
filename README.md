# Daily Report
日々の学びと経験を記録するリポジトリ

## 目的
- 一度聞いたことを忘れないようにする
- 一度体験したことを形式知化する
- 知識を検索可能な形で蓄積する

## 使い方
### 📋 今日のタスク
**朝一番に記入** - 今日やる予定のことをチェックボックスで記入

- 前日の「明日やること」を転記
- 定例会議やミーティング
- 取り組む予定の開発タスク
- 調べたいこと、聞きたいこと

チェックボックス `- [ ]` を使うことで、完了時に `- [x]` に変更できる

### 📝 出来事・メモ（時系列）
**メインセクション** - 仕事中に起きたことをその都度追記

書く内容の例：
- 会議での決定事項や聞いた話
- 実行したコマンドやトラブルシューティング
- 質問した内容と回答
- レビューでのフィードバック
- ドキュメントを読んで理解したこと

**書き方のコツ**：
- 後回しにせず、その都度メモする（5秒でOK）
- 完璧な文章でなくてOK、箇条書きやメモ書きで素早く記録
- コードやコマンドはコピペして、後で再現できるようにしておく
- 重要度に関わらず、気になったことは何でも書く

### ✅ 今日やったこと
終業時に時系列セクションを見返してサマリーを記入

### 💭 気づき・学び
特に重要な学びや気づきをピックアップ

### ❓ 疑問点・明日やること
解決していない疑問点や、明日やるべきことをメモ

### 🏷️ タグ
後で検索しやすいようタグを付与（技術名、プロジェクト名など）
